2. big-picture
- tcp/ip protocol suite is much more than just tcp, ip
- tcpdump use bpf/dlpi interface to unormally access datalink without socket, except linux through sock_packet socket
- traceroute use both socket for ip and icmp
- IPv4 is born in 1981, use 32-bit to present address, provide packet delivery based on the address for TCP, UDP, SCTP, ICMP và IGMP
- ipv6 is born 1998 to meet explosion of internet by using 128-bit address, provide packet delivery based on the address for TCP, UDP, SCTP và ICMPv6
- tcp is connection-oriented, byte-stream protocol, full-duplex, reliable, stream socket, handle ack->timeout->retransmission, run on top of ip
- udp is connectionless, unreliable, datagram socket, run on top of ip
- sctp support multihoming so the connection of 2 endpoint is called association(ips,port<->ips,port), it is connection-oriented connection must establish, meaning both should on the meeting room, meaning they ready to listen to the other, full-deplex meaning no need to wait cli msg come before server sending, record boundaries each read is actually a full message, use both ip in one version
