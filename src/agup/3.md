# 3. Your First Programs

## Entering in the Program
- `source code`: human program
- `object file`: half machine program
- `executable`: structured machine program kernel know how to load && run, unified object files
- `coder` -> `assemblers` -> `linker` -> `runner`
- `exit status`: program signal caller how to handle if fail when done in number way
## Outline of an Assembly Language Program
- `#`: comment of code purpose, steps overview, strange behavior 
- `assembler directive` || `pseudo-op`: start `.`, assembler's instruction
- `.section`: break program to sections
  - `.data`: memory data
  - `.text`: program instructions
- `.globl _start`: mark _start as global starter symbol
- `symbol`: symbolic name of marked point address
- `label`: define symbol's value
- `$`: indicate number
- system call paraming process, `int $0x80`: signal Kernel do the job then comeback, jump to interupt handler location -> jump back to next line
- flow control: decide instruction path, up||down
  - `conditional jump`: cmpl(c=b-a) -> je(c==0,jmp)
  - `unconditional jump`: jump whatever
- `loop`: cmp + jmp
## Planning the Program
- plan:
  - Where will the original list of numbers be stored?
  - What procedure will we need to follow to find the maximum number?
  - How much storage do we need to carry out that procedure?
  - Will all of the storage fit into registers, or do we need to use some memory as well?
- assumption:
  - data_items:
  - zero to stop
  - %edi: current position in the list, =0
  - %ebx: current highest value in the list, =first item
  - %eax: current element being examined, =first item
- step:
1. Check the current list element (%eax) to see if it’s zero (the terminating element)
2. If it is zero, exit
3. Increase the current position (%edi).
4. Load the next value in the list into the current value register (%eax). What addressing mode
might we use here? Why?
5. Compare the current value (%eax) with the current highest value (%ebx).
6. If the current value is greater than the current highest value, replace the current highest value
with the current value
7. Repeat
