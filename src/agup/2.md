# 2. Computer Architecture
- nature Neumann arch: computer divided to `cpu` and `memory`

## Structure of Computer Memory
- `memory`: fixed-size storage locations storing only number
- (program’s data == data) on `memory`: stored and accessed the same way
- Thus, if instruction pointer point to memory word, cpu load as instruction
## CPU
- cpu read instruction from memory one at time and execute them, called `fetch-execute cycle`
- mechanism:
  - cpu load next instruction from address holding by `program counter`
  - then pass to `instruction decoder`, it extract instruction meaning && data addresses that belong to the process
  - then cpu send signals to load all of the data it needs from `memory` to `general-purpose registers` for processing
  - then pass the `data` and `operand` to `ALU`
  - then return to either memory or register
  - load/store memory operation is done through `data bus` bridge
## Some Terms
- `address`: number attach to each location
- `byte`: number representation, size of one location, byte combination for bigger
- `register`: yur desk, keep currently manipulating `bytes`
- `word`: `register` size || `computer` size || `address` size, cpu processed in one go
- `pointer`: address in memory
- All computer things are numbers, specialized intepretation determine what mean
## Interpreting Memory
- computer do exactly what u tell
- store info, chunk by chunk || pointer by pointer
- records fixed length, variable-length elsewhere
## Data Accessing Methods
- `addressing mode`: how cpu find its operand
- value:
  - `immediate`: regis=0 -> regis=0
  - `register addressing`: regis=regis1 -> regis=regis1
- address:

| var             | value                          |
|-----------------|--------------------------------|
| MEM[1500,..,+=word-1]     | 2004                 |
| MEM[2004,..,+=word-1]     | 22                   |
| regis_INDEX     | 1                              |
| regis_INDIRECT  | 1500                           |
| regis_BASE      | 1492                           |
| SCALE           | 4                              |
| OFFSET          | 8                              |

  - `direct addressing`: regis=[2004] -> regis=22
  - `indexed addressing`: regis=[2000 + regis_INDEX * SCALE] -> regis=22
  - `indirect addressing`: regis=[ [regis_INDIRECT] ] -> regis=22
  - `base pointer addressing`: regis=[ [regis_BASE + OFFSET] ] -> regis=22
